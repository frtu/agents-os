# Template — Mid-year review (continue / stop / start)

Use for a lighter mid-cycle review conversation or write-up. Pairs with Case S and `../guides/performance-and-1on1.md`.

```markdown
# [Name] — H1 review

**Overall:** [rating + one line; "on track is a good answer"]

## Context
[Purpose: capture a mind map now so year-end is easy; growth isn't linear across dimensions.]

## Continue  (specific behaviors + recent example each)
- [Behavior] — e.g. [example, date/project]
- [An image that sticks: "muscle built for real use, not gym muscle"]

## Stop / improve  (framed as balance, not fault)
- [WHEN decomposition / escalate earlier / strict→judgement / make depth visible]
- Manager's share: [what I did that contributed]

## Start
- [Measure outcomes / co-build with peers / next rung of the influence ladder]

## Next half
[One outcome that would surprise the boss.]
```

**Section insight**
- One example per point, or the point is cut.
- A person's signature strength appears in Continue *and* is calibrated in Improve. Never only the second.
- Tell promotions and comp outcomes yourself, before the HR system releases them.
