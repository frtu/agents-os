# Case Q — Annual budget built on an imposed number

- **Before:** *"Next year: last year's budget + 10%."*
- **Common approach:** extrapolate and pad.
- **Why this one diverges:** zero-based scrutiny is coming. Every vendor needs a justification and an owner. A number that can't be explained loses credibility for every later request.
- **Interrogation:** *"Is the baseline the real spend or last year's target?"* (4). *"Which lines are run / scale / change the business?"* *"How confident is each number?"*
- **What surfaces:** last year's figure was reverse-engineered, strategic projects are missing, and part of the spend belongs to other teams' growth.
- **Distilled (what to do):** re-baseline on reality. Organic growth (regression) plus strategic projects added by hand, modelled on a known baseline with a ramp-up. Plan for the maximum plausible case and let finance decide; later requests then go to finance. State each number's confidence. A P75 scenario, not the worst case. Rough on Friday, refined next week. Don't forecast other teams' growth.
- **Lesson:** "rough is OK as long as it's explainable."
