# Case Registry

Worked examples of a finished prep (candidate page + question guide), each showing a particular shape of round. They show what "good" looks like and keep recurring failure shapes on record. The templates stay generic; the specifics live here.

**Load a case** only when the current prep matches its step and shape (see the table). Never load all of them.

## Adding a case

1. Name it `{letter}-{slug}.md`, using the next letter (a, b, c…) and a slug for the pattern (e.g. `a-aligned-resume-comfortable-retro`), not a person's name.
2. Anonymise it: no real candidate names, no internal URLs. Link to the real wiki pages in the vault instead of copying them.
3. Structure:
   - **Situation**: step, floor/target/stretch, the round's load (SKILL.md step 3b).
   - **What the prep did**: the central probe, the step-specific section, the category choices.
   - **What went wrong / right**: the failure shape or the good practice it shows.
   - **Rule**: the lesson in one line. If it holds across ≥2 cases, promote it to a template or the Quality Checklist.
4. Add a row to the table above.
