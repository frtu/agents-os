# Template — Pitch review scorecard

Use in Pitch review mode to score a deck against the Pitch Checks (P1–P12 in `SKILL.md`), and after each real pitch as a debrief. Pairs with every case.

```markdown
# Pitch review — [deck] — audience: [...]

| Check | Status (✅ / ⚠️ / ❌) | Evidence from the deck (quote, slide #) | Case |
|-------|---------------------|-----------------------------------------|------|
| P1 Audience-fit pitch | | | A |
| P2 Concrete one-liner | | | B |
| P3 Problem slice, payer view, today's workflow | | | C |
| P4 Quantified before/after; built now; usage not features | | | D |
| P5 Evidence = past behaviour / commitments | | | H |
| P6 Hero facts, defined, trended | | | E |
| P7 Bottoms-up market | | | G |
| P8 Credibility before vision | | | F |
| P9 Insight, moat, why now, honest competition | | | — |
| P10 One idea per slide, legible/simple/obvious | | | J |
| P11 Explicit ask + milestone | | | I |
| P12 Overview + appendix ready for Q&A | | | J |

## Debrief (after a real pitch)
| Leaned in on | Zoned out on | Objections (weak answers) | Weakest spine claim | Deck change |
|--------------|--------------|---------------------------|---------------------|-------------|
```
